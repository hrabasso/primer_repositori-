# Fitxa tècnica: Ús de ChatGPT

## Objectiu

Aprendre a utilitzar ChatGPT per obtenir informació i crear un resum a partir d'un text.

## Materials

* Ordinador
* Connexió a Internet
* Navegador web
* ChatGPT

## Procediment

1. Obrir el navegador web.
2. Entrar a ChatGPT.
3. Escriure un text o una pregunta.
4. Demanar a ChatGPT que faci un resum.
5. Revisar la resposta obtinguda.

Per exemple, podem escriure:

```text
Fes un resum d'aquest text en 5 línies.
```

## Comprovacions

* [ ] ChatGPT s'obre correctament.
* [ ] La pregunta s'envia correctament.
* [ ] ChatGPT genera una resposta.
* [ ] El resum és correcte.

## Incidències i solucions

| Incidència              | Solució                           |
| ----------------------- | --------------------------------- |
| ChatGPT no carrega      | Comprovar la connexió a Internet. |
| No respon               | Tornar a enviar la pregunta.      |
| El resum no és correcte | Fer una pregunta més específica.  |
